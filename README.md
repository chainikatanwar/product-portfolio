# Product Portfolio — Chainika Tanwar

Product management case studies from the **Airtribe Product Management Launchpad** (completed October 2026): user research, usability audits, PRDs, metrics, system design and product strategy.

Each folder holds one assignment: a short summary, a cover preview, and the original deck or document.

**Portfolio site:** [chainikatanwar.github.io](https://chainikatanwar.github.io/)
